Мониторинг ОПРЧ v1.8.2 — пакет для сотрудников
==============================================

Универсальная программа: любая электростанция, любое событие.
Событие задаёте сами на листах RawData (ряды) и Config (оборудование).
Вкладки «Запрос» нет — коды запросов к ОИК храните отдельно.

Главный файл
------------
• Шаблон_мониторинг_ОПРЧ.xlsm  ← ОТКРОЙТЕ ЕГО (макросы уже внутри)

Как пользоваться
----------------
1. Откройте Шаблон_мониторинг_ОПРЧ.xlsm.
2. Разрешите макросы (жёлтая строка сверху).
3. Замените демо в RawData / Config своими данными станции и события.
4. Первый запуск: Alt+F8 → AnalyzeOPRCH → Выполнить
   (появятся кнопки на Config; дальше можно жать «Запустить мониторинг ОПРЧ»).

Не запускайте SetupOPRCHTemplate на заполненной книге.

Запасной путь (если xlsm не открывается)
----------------------------------------
См. КАК_ИМПОРТИРОВАТЬ_VBA.txt — шесть модулей *_win1251.bas + Install.
Причина разбиения на 6: один большой модуль Sheets превышал лимит VBA ~64 КБ.
