Установка макроса ОПРЧ v1.8.1 (универсальный шаблон)
====================================================

Программа не привязана к одной станции: событие задаёте в RawData и Config.

Рекомендуемый способ
--------------------
1. Откройте Шаблон_мониторинг_ОПРЧ.xlsx из этой папки.
2. «Сохранить как» → Книга Excel с поддержкой макросов (*.xlsm)
   в ЭТУ ЖЕ папку (рядом с файлами *_win1251.bas).
3. Excel: Файл → Параметры → Центр управления безопасностью →
   Параметры центра… → Параметры макросов →
   включите «Доверить доступ к объектной модели проектов VBA».
4. Alt+F11 → File → Import File… → выберите ТОЛЬКО
   OPRCH_Install_win1251.bas
5. Alt+F8 → InstallOPRCHMacros.
6. Подставьте свои данные в RawData/Config (демо можно заменить).
7. Config → «Запустить мониторинг ОПРЧ».

НЕ запускайте SetupOPRCHTemplate на заполненной книге — сотрёт данные.
Вкладки «Запрос» в книге нет — запросы к ОИК храните отдельно.

Запасной способ (пять файлов вручную)
-------------------------------------
Импорт по порядку:
  1) OPRCH_Common_win1251.bas
  2) OPRCH_Engine_win1251.bas
  3) OPRCH_Sheets_win1251.bas
  4) OPRCH_Charts_win1251.bas
  5) OPRCH_Monitor_win1251.bas
Затем Debug → Compile VBAProject, Alt+F8 → AnalyzeOPRCH.

Один запуск AnalyzeOPRCH = колич. + кач. сразу.
Режим Config X13: «Авария» / «Испытание».
