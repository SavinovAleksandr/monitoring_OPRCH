Импорт макроса ОПРЧ v1.7.1 в Excel (русская Windows)
====================================================

Почему один файл не импортировался
- Модуль был ~217 КБ. У VBA лимит около 64 КБ скомпилированного кода на модуль.
- Файл UTF-8 на русской Windows даёт «синтаксис» из‑за кириллицы.
- Нужны файлы *_win1251.bas (Windows-1251, перевод строки CRLF).

Почему шаблон «битый»
- Исходный «Шаблон_мониторинг ОПРЧ.xlsx» записан как strict OOXML.
  Excel часто открывает его через восстановление.
- Берите Шаблон_мониторинг_ОПРЧ_ВТЭЦ-2_31.10.2026.xlsx из репозитория.

Порядок
1. Откройте Шаблон_мониторинг_ОПРЧ_ВТЭЦ-2_31.10.2026.xlsx
   и сразу «Сохранить как» → Книга Excel с поддержкой макросов (*.xlsm).
2. Alt+F11.
3. File → Import File…  строго по очереди:
   1) OPRCH_Common_win1251.bas
   2) OPRCH_Engine_win1251.bas
   3) OPRCH_Sheets_win1251.bas
   4) OPRCH_Charts_win1251.bas
   5) OPRCH_Monitor_win1251.bas
4. Debug → Compile VBAProject.
5. Alt+F8 → AnalyzeOPRCH.

Не запускайте SetupOPRCHTemplate на этом шаблоне — он сотрёт RawData и Config.
Не импортируйте файлы без суффикса _win1251 и не импортируйте OPRCH_Monitor_all.bas.
