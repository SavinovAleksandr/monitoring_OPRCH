Запасная установка макроса ОПРЧ v1.8.3
=====================================

Обычный путь: откройте готовый Шаблон_мониторинг_ОПРЧ.xlsm — импорт не нужен.
На Mac: Option+F8 (или Сервис → Макрос → Макросы) → AnalyzeOPRCH.

Если нужно поставить макросы вручную в пустую книгу:

1. Откройте Шаблон_мониторинг_ОПРЧ.xlsx (без макросов).
2. «Сохранить как» → Книга Excel с поддержкой макросов (*.xlsm)
   в ЭТУ ЖЕ папку (рядом с файлами *_win1251.bas).
3. Excel → Параметры → Центр управления безопасностью → Параметры макросов →
   включить «Доверить доступ к объектной модели проектов VBA».
4. Alt+F11 → File → Import File →
   OPRCH_Install_win1251.bas
5. Alt+F8 → InstallOPRCHMacros.

Установщик сам подтянет шесть модулей:
  1) OPRCH_Common_win1251.bas
  2) OPRCH_Engine_win1251.bas
  3) OPRCH_Station_win1251.bas
  4) OPRCH_Sheets_win1251.bas
  5) OPRCH_Charts_win1251.bas
  6) OPRCH_Monitor_win1251.bas

Важно: модули должны быть в кодировке Windows-1251 (суффикс _win1251).
Не импортируйте UTF-8 .bas на русской Windows — будут кракозябры.
Каждый модуль < 55 КБ (лимит VBA ~64 КБ на модуль).
