Установка макроса ОПРЧ v1.8.0 (один импорт вместо пяти)
=======================================================

Рекомендуемый способ (готовый шаблон ВТЭЦ-2)
--------------------------------------------
1. Откройте Шаблон_мониторинг_ОПРЧ_ВТЭЦ-2_31.10.2026.xlsx
   из этой папки (не старый файл из Downloads).
2. «Сохранить как» → Книга Excel с поддержкой макросов (*.xlsm)
   в ЭТУ ЖЕ папку (рядом с файлами *_win1251.bas).
3. Excel: Файл → Параметры → Центр управления безопасностью →
   Параметры центра… → Параметры макросов →
   включите «Доверить доступ к объектной модели проектов VBA».
4. Alt+F11 → File → Import File… → выберите ТОЛЬКО
   OPRCH_Install_win1251.bas
5. Alt+F8 → InstallOPRCHMacros.
   Установщик сам подтянет пять модулей и сохранит .xlsm.
6. Откройте лист «Инструкция», затем Config →
   «Запустить мониторинг ОПРЧ».

НЕ запускайте SetupOPRCHTemplate на этом шаблоне — сотрёт RawData/Config.

Запасной способ (пять файлов вручную)
-------------------------------------
Импорт по порядку:
  1) OPRCH_Common_win1251.bas
  2) OPRCH_Engine_win1251.bas
  3) OPRCH_Sheets_win1251.bas
  4) OPRCH_Charts_win1251.bas
  5) OPRCH_Monitor_win1251.bas
Затем Debug → Compile VBAProject, Alt+F8 → AnalyzeOPRCH.

Почему не один .bas
-------------------
Лимит VBA ~64 КБ скомпилированного кода на модуль.
Нужны файлы *_win1251.bas (Windows-1251, CRLF), не UTF-8.

Почему нет готового .xlsm «из коробки» на Mac
---------------------------------------------
Автоматическая сборка .xlsm с VBA через Excel на macOS в этой среде
не сохраняет файл. Установщик выше даёт тот же результат за один импорт.

Что считается одним запуском
----------------------------
AnalyzeOPRCH сразу делает количественную (Прил. 14) и качественную
(типы реакции 4.4 + ступени t5/t10) оценку. Отдельно запускать
«только колич.» / «только кач.» не нужно.
Режим Config X13:
  Авария  — мониторинг событий; t5/t10 справочно; дефицит → НАРУШЕНИЕ.
  Испытание — контрольные испытания; несданные t5/t10 → НАРУШЕНИЕ.
